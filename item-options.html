Complete Field Reference ​

This page lists the fields you can use when creating an item in a business file.

Most items should use this shape:

lua
OGConsumable.RegisterCategory(business, 'category_name', 'food', {
    item_name = {
        label = 'Item Label',
        hunger = 50,
        progress = 'Eating...',
        ox = {
            description = 'Inventory description.',
            weight = 200,
            image = 'item_name.png'
        }
    }
})

Register Functions ​

FunctionUse WhenNotes
OGConsumable.RegisterCategory(business, category, type, items)Normal business filesBest default. Adds business, category, and type to each item.
OGConsumable.RegisterDrink(business, itemName, data)One drink itemDefaults thirst to 45, duration to 5, and creates drink text if missing.
OGConsumable.RegisterFood(business, itemName, data)One food itemDefaults hunger to 35, duration to 6, and creates eat text if missing.
OGConsumable.Register(type, business, itemName, data)Special manual registrationUse for custom types such as misc.
OGConsumable.RegisterMany(type, business, items)Bulk registration without categoriesLess organized than categories.

Type Defaults ​

TypeDefault ProgressDefault AnimationTypical Use
drinkDrinking..., 5000msDrink loopSoda, beer, cocktails, coffee
foodEating..., 5000msBurger eat animMeals, snacks, desserts
miscUsing..., 1000msDisabledDog treats, special usable items

Business helper durations can be seconds or milliseconds. Values <= 600 are treated as seconds; values > 600 are treated as milliseconds.

Basic Fields ​

FieldTypeExampleWhat It Does
labelstring'Fireside Cola'Display name used in notifications, generated ox label, and docs/debug output.
hunger / Hungernumber65Adds to hunger after successful use.
thirst / Thirstnumber75Adds to thirst after successful use.
stress / Stressnumber5Positive numbers lower stress. Negative numbers increase stress.
log / Logstring'You drank cola.'Success notification after the item completes.
messagestring'You feel better.'Fallback success notification if log is not set. Also used in restrictions as a block message.
progress / ProgressBarstring'Drinking Cola...'Text shown in the ox_lib progress UI.
durationnumber5 or 5000Progress duration. 5 means 5 seconds; 5000 means 5000ms.
cooldownnumber2500Per-player delay before this same item can be used again, in milliseconds.
categorystring'house_drinks'Usually set by RegisterCategory; used for listing/filtering.
typestring'drink'Usually set by the register function; controls defaults.

Inventory Fields ​

Default behavior removes one of the item being used.

FieldTypeExampleWhat It Does
removebooleanfalseSet false to stop the used item being removed.
countnumber2Number of the used item to remove when using default removal.
removeItemstableSee belowExact items to remove instead of only the used item.
addbooleanfalseSet false to stop configured addItems from being added.
addItemstableSee belowItems to give after successful use.
dirtyItemstring'gp_dirtyglass'Shortcut that adds one return item after use.
dirtyCountnumber1Count for dirtyItem.
dirtyMetadataboolean/table/stringtrueMetadata to place on the dirty return.
requiredItemstableSee belowItems required before use, but not removed.
requiretableSee belowAlias for requiredItems.

Remove Items ​

lua
removeItems = {
    { item = 'wrapped_food', count = 1 },
    { item = 'napkin', count = 1 }
}

Add Items ​

lua
addItems = {
    { item = 'wrapper', count = 1 },
    { item = 'gp_dirtyplate', count = 1 }
}

Required Items ​

lua
requiredItems = {
    { item = 'spoon', count = 1 }
}

Required items are checked before use. They are not removed unless you also list them in removeItems.

Item List Entries ​

Used by removeItems, addItems, requiredItems, inventory.remove, and inventory.add.

FieldTypeExampleWhat It Does
item / namestring'gp_dirtyglass'Item name.
count / amountnumber1Item count. Defaults to 1.
metadataboolean/table/stringtrueMetadata requirement or generated metadata.
slotnumber4Specific ox inventory slot for add/remove. Rarely needed.

Shortcut map format also works:

lua
removeItems = {
    gp_ticket = 1,
    gp_coupon = 2
}

Metadata Fields ​

Metadata can be copied or built from the item being used.

Metadata ValueWhat It Does
metadata = trueCopies all metadata from the used item.
metadata = 'copy'Same as true.
metadata = 'source'Same as true.
metadata = 'source.batch'Copies one metadata key from the used item.
metadata = 'metadata.batch'Same as source.batch.
metadata = 'context.itemName'Copies a runtime context value.
metadata = { ... }Builds a new metadata table; each value can use the same copy rules.

Available context.* values:

Context ValueMeaning
context.sourcePlayer server ID.
context.item / context.itemNameName of the item being used.
context.labelConsumable label.
context.businessBusiness name.
context.categoryCategory name.
context.typeItem type.
context.slotOx inventory slot when available.
context.metadataMetadata from the used item.

Example:

lua
addItems = {
    {
        item = 'empty_bottle',
        count = 1,
        metadata = {
            originalItem = 'context.itemName',
            batch = 'source.batch',
            maker = 'metadata.maker',
            returnedBy = 'context.source'
        }
    }
}

Advanced Inventory Object ​

The server can also read an inventory table. Most business files should use the simpler top-level fields above.

FieldTypeWhat It Does
inventory.removetableOverride remove item list.
inventory.addtableOverride add item list.
inventory.consumenumberCount of the used item to remove.
inventory.consumeSelfbooleanSet false to stop default self-removal.

Example:

lua
inventory = {
    consumeSelf = false,
    remove = {
        { item = 'sealed_box', count = 1 }
    },
    add = {
        { item = 'empty_box', count = 1 }
    }
}

Ox Fields ​

The ox block is used by tools/export-ox-items.ps1 to generate ox item files.

FieldTypeExampleWhat It Does
ox.descriptionstring'A cold cola.'Inventory description.
ox.weightnumber130Ox item weight.
ox.imagestring'gp_stagcola.png'Inventory image filename.
ox.stackbooleantrueWhether ox stacks the item.
ox.closebooleantrueWhether inventory closes on use.
ox.consumenumber0Must stay 0 so ox does not remove the item before OG handles it.
ox.degradenumber1440Ox durability/degrade time in minutes.
ox.decaybooleantrueWhether ox removes the item at 0 durability.
ox.exportstring'og_consumable.UseConsumable'Server export ox calls when item is used.

Top-level aliases also work for exporter values:

lua
description = 'Inventory description.'
weight = 200
image = 'item_name.png'
stack = true
close = true
consume = 0
degrade = 1440
decay = true
export = 'og_consumable.UseConsumable'

Prefer the ox = { ... } block because it keeps inventory data easy to scan.

Effects ​

Effects run after the item succeeds.

FieldTypeExampleWhat It Does
effects.healthnumber10Adds health, clamped to max health.
effects.armor / effects.armournumber25Adds armor, clamped 0-100.
effects.staminanumber/table25Restores stamina once, or repeatedly with duration.
effects.speednumber/table1.12Temporary run/swim multiplier.
effects.walkstring/table'move_m@drunk@slightlydrunk'Temporary movement clipset.
effects.screenstring/table'DrugsMichaelAliensFight'GTA screen effect.
effects.timecyclestring/table'spectator5'Temporary timecycle modifier.
effects.shakenumber/table0.35Temporary gameplay camera shake.
effects.clientEventstring'my:client:event'Client event triggered with the effects table.
effects.serverEventstring'my:server:event'Server event triggered with source, item, config, and metadata context.
clientEventstring'my:client:onUse'Top-level client event after success.
serverEventstring'my:server:onUse'Top-level server event after success.

Full example:

lua
effects = {
    health = 10,
    armor = 5,
    stamina = {
        restore = 25,
        duration = 8000,
        interval = 1000
    },
    speed = {
        multiplier = 1.12,
        swimMultiplier = 1.05,
        duration = 12000
    },
    walk = {
        clipset = 'move_m@drunk@slightlydrunk',
        duration = 30000,
        transition = 0.25
    },
    screen = {
        effect = 'DrugsMichaelAliensFight',
        duration = 8000,
        looped = false
    },
    timecycle = {
        modifier = 'spectator5',
        strength = 0.45,
        duration = 15000
    },
    shake = {
        type = 'DRUNK_SHAKE',
        intensity = 0.35,
        duration = 8000
    }
}

Effect duration uses the same duration rule: values <= 600 are seconds; values > 600 are milliseconds.

Stamina Effect ​

FieldTypeWhat It Does
restore / amountnumberStamina amount. 25 means 25%; 1.0 means 100%.
durationnumberHow long to keep restoring stamina.
intervalnumberHow often to restore during the duration.
lua
stamina = {
    restore = 100,
    duration = 600,
    interval = 500
}

FieldTypeWhat It Does

FieldTypeWhat It Does

Screen, Timecycle, And Shake Effects ​

FieldTypeWhat It Does

Alcohol ​

Use alcohol only for BAC/drunk behavior. Keep progress, thirst, stress, removal, and dirty returns in OG.

FieldTypeExampleWhat It Does
alcohol.enabledbooleanfalseDisables alcohol for this item when false.
alcohol.providerstring'nrg'Alcohol provider. Currently supports nrg / nrg_alcoeffect.
alcohol.drunk / amount / levelnumber0.20Drunk/BAC amount passed to NRG.
alcohol.resourcestring'nrg_alcoeffect'Override NRG resource name.
alcohol.propstring'prop_mojito'Prop passed to NRG, if NRG uses it.
alcohol.propOffset / propoffset / offsettable{ x = 0.12, y = -0.03, z = 0.055 }Prop offset passed to NRG.
alcohol.notifyboolean/stringfalsefalse prevents duplicate NRG notify; true sends OG log; string sends custom NRG notify.

Example:

lua
alcohol = {
    drunk = 0.20,
    provider = 'nrg',
    prop = 'prop_mojito',
    propOffset = { x = 0.12, y = -0.03, z = 0.055 },
    notify = false
}

Restrictions ​

Use restrictions for locked items.

FieldTypeExampleWhat It Does
restrictionstableSee belowMain restriction config.
restricttableSee belowAlias for restrictions.
useRestrictionstableSee belowAlias for restrictions.
restrictions.modestring'any'any allows if one configured rule passes. all requires every rule to pass.
restrictions.whitelistbooleantrueAllows runtime item whitelist entries.
restrictions.itemWhitelistbooleantrueAlias for whitelist.
restrictions.pedstable/string{ 'a_c_chop' }Allowed ped model names or hashes.
restrictions.allowedPedstable/string{ 'a_c_husky' }Alias for peds.
restrictions.pedModelstable/string{ 'a_c_shepherd' }Alias for peds.
restrictions.modelstable/string{ 'a_c_rottweiler' }Alias for peds.
restrictions.acestring'og_consumable.admin'ACE permission that can allow use.
restrictions.permissionstring'og_consumable.admin'Alias for ace.
restrictions.citizenidstable/string{ 'ABC12345' }Static allowed framework citizen IDs.
restrictions.citizenIdstable/string{ 'ABC12345' }Alias for citizenids.
restrictions.citizenidstring'ABC12345'Single citizen ID.
restrictions.citizenIdstring'ABC12345'Alias for citizenid.
restrictions.messagestring'Only dog peds can use this.'Block message when use is denied.

Example:

lua
restrictions = {
    mode = 'any',
    whitelist = true,
    citizenids = {
        'ABC12345'
    },
    peds = {
        'a_c_chop',
        'a_c_husky',
        'a_c_shepherd'
    },
    message = 'Only dog peds can use this treat.'
}

Runtime whitelist JSON:

json
{
  "pd_dog_treat": {
    "item": "pd_dog_treat",
    "label": "Police Dog Treat",
    "citizenids": [
      "ABC12345"
    ]
  }
}

Full Example ​

lua
local business = 'blackstag'

OGConsumable.RegisterCategory(business, 'house_drinks', 'drink', {
    gp_stagcola = {
        label = 'Fireside Cola',
        thirst = 75,
        stress = 2,
        log = 'You drank a spiced cola.',
        progress = 'Drinking Cola...',
        duration = 5,
        cooldown = 1500,
        propPreset = 'drink',
        dirtyItem = 'gp_dirtyglass',
        dirtyMetadata = true,
        effects = {
            stamina = 10
        },
        ox = {
            description = 'A Warming, Spiced Cola.',
            weight = 50,
            image = 'gp_stagcola.png',
            degrade = 1440,
            decay = true
        }
    }
})
