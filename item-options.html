Item Options ​

Use Full Item Template as the copy-paste reference.

Registering Items ​

Preferred shape:

lua
OGConsumable.RegisterCategory(business, 'category_name', 'food', {
    item_name = {
        label = 'Item Label'
    }
})

The category name is only for organization. The type controls defaults and behavior:

text
drink
food

Common Fields ​

lua
label = 'Display Name'
hunger = 50
thirst = 50
stress = 5
log = 'You used the item.'
progress = 'Using...'
duration = 6
cooldown = 2500

Positive stress lowers stress. Negative stress increases stress.

Inventory ​

Default behavior removes one of the item used.

lua
remove = true
count = 1

Dirty return shortcut:

lua
dirtyItem = 'dirty_plate'
dirtyCount = 1

Manual remove/add:

lua
removeItems = {
    { item = 'wrapped_food', count = 1 }
}

add = true
addItems = {
    { item = 'wrapper', count = 1 }
}

Metadata-aware add/remove/required entries:

lua
addItems = {
    -- Copies all metadata from the used item.
    { item = 'dirty_plate', count = 1, metadata = true },

    -- Builds fresh metadata using static values and values from the used item.
    {
        item = 'empty_bottle',
        count = 1,
        metadata = {
            business = 'Black Stag',
            maker = 'source.maker',
            batch = 'source.batch',
            originalItem = 'context.itemName'
        }
    }
}

Use source.field or metadata.field to copy one metadata value from the used item. Use context.itemName, context.label, context.business, context.category, context.type, or context.slot for consumable context.

Dirty return with metadata:

lua
dirtyItem = 'dirty_plate'
dirtyMetadata = true

Required but not removed:

lua
requiredItems = {
    { item = 'spoon', count = 1 }
}

Restrictions ​

Use restrictions for items only certain peds, ACE permissions, citizen IDs, or item whitelists should use.

lua
restrictions = {
    mode = 'any',
    whitelist = true,
    citizenids = {
        'ABC12345'
    },
    peds = {
        'a_c_chop',
        'a_c_husky',
        'a_c_retriever',
        'a_c_rottweiler',
        'a_c_shepherd'
    },
    message = 'Only dog peds can use this treat.'
}

mode = 'any' means any configured rule can allow the item. mode = 'all' means every configured rule must pass.

Runtime whitelist command:

text
/ogc_whitelist add pd_dog_treat playerId
/ogc_whitelist add pd_dog_treat citizenid
/ogc_whitelist remove pd_dog_treat playerId
/ogc_whitelist remove pd_dog_treat citizenid
/ogc_whitelist list pd_dog_treat
/ogc_whitelist clear pd_dog_treat

Runtime whitelists are saved in data/whitelists.json by item:

json
{
  "pd_dog_treat": {
    "item": "pd_dog_treat",
    "label": "Police Dog Treat",
    "citizenids": [
      "ABC12345"
    ]
  }
}

Props And Animation ​

Preset:

lua
propPreset = 'burger'

Available presets:

text
drink
coffee
bottle
food
burger
snack
bowl

Simple prop override:

lua
prop = 'prop_food_juice02'

Full prop override:

lua
prop = {
    model = 'prop_food_juice02',
    bone = 60309,
    pos = vec3(0.0, 0.0, -0.05),
    rot = vec3(0.0, 0.0, -40.0)
}

Simple animation override:

lua
anim = {
    dict = 'mp_player_intdrink',
    clip = 'loop_bottle',
    flag = 49
}

Scenario:

lua
scenario = 'WORLD_HUMAN_DRINKING'

Disable animation or prop:

lua
animation = false
prop = false

Effects ​

Effects run after progress completes.

lua
effects = {
    health = 10,
    armor = 5,
    stamina = 25
}

Timed effects:

lua
effects = {
    stamina = {
        restore = 25,
        duration = 8000
    },
    speed = {
        multiplier = 1.12,
        duration = 12000
    },
    walk = {
        clipset = 'move_m@drunk@slightlydrunk',
        duration = 30000
    },
    screen = {
        effect = 'DrugsMichaelAliensFight',
        duration = 8000
    },
    timecycle = {
        modifier = 'spectator5',
        strength = 0.45,
        duration = 15000
    },
    shake = {
        type = 'DRUNK_SHAKE',
        intensity = 0.35,
        duration = 8000
    }
}

Custom events:

lua
effects = {
    clientEvent = 'my_resource:client:customEffect',
    serverEvent = 'my_resource:server:customEffect'
}

clientEvent = 'my_resource:client:onConsumableUsed'
serverEvent = 'my_resource:server:onConsumableUsed'

Alcohol / NRG AlcoEffect ​

For alcohol, keep thirst, stress, progress, props, removal, and dirty returns in og_consumable. Use alcohol only for BAC/drunk behavior.

lua
alcohol = {
    drunk = 0.20,
    provider = 'nrg',
    prop = 'prop_mojito',
    propOffset = { x = 0.12, y = -0.03, z = 0.055 },
    notify = false
}

notify = false avoids a second NRG notification. Use notify = true to pass the OG item log to NRG, or set a custom string.

For items controlled by og_consumable, do not configure thirst, stress, or item removal in nrg_alcoeffect. Let OG call NRG after the item succeeds.

Ox Metadata ​

lua
ox = {
    description = 'Inventory description.',
    weight = 200,
    image = 'item_name.png',
    stack = true,
    close = true,
    consume = 0,
    degrade = 1440,
    decay = true,
    export = 'og_consumable.UseConsumable'
}

Most items should leave consume = 0 and export alone.
