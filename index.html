OG Consumable ​

og_consumable is a config-driven consumable system for Qbox/QBCore servers using ox_inventory and ox_lib.

It is intended to be the source of truth for food, drink, and future consumable-style items. Add items here first, then generate matching ox_inventory item files from the same config.

What It Handles ​

  • Progress bars/circles and cancellation.
  • Item removal, dirty returns, and add items.
  • Hunger, thirst, and stress changes.
  • Per-item props, animations, scenarios, and disabled animation.
  • Per-item effects like stamina, armor, health, speed, walk styles, screen effects, and events.
  • Alcohol handoff to nrg_alcoeffect.
  • Runtime citizen ID whitelists for restricted items.
  • Generated ox_inventory item files with the correct server export.

Quick Example ​

lua
local business = 'kff'

OGConsumable.RegisterCategory(business, 'drinks', 'drink', {
    kff_orange_soda = {
        label = 'Orange Soda',
        thirst = 60,
        stress = 2,
        progress = 'Drinking Soda...',
        propPreset = 'drink',
        ox = {
            description = 'A cold fizzy orange drink.',
            weight = 130,
            image = 'kff_orange_soda.png'
        }
    }
})
