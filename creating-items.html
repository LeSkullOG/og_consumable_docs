Creating Items ​

This is the normal flow for adding a consumable without getting lost in the full reference.

1. Pick A Business File ​

Business files live here:

text
shared/consumables/businesses/

For a new business, create a new file:

powershell
.\tools\ps1\new-business.ps1 -Business kff -Label "Korean Fried Finest" -Apply

2. Pick A Category And Type ​

Use categories to keep a business file readable. The category name is just organization.

The type controls default behavior:

TypeUse ForDefaults
drinkDrinks, cocktails, coffee, sodaDrink animation, 5 seconds, thirst default
foodMeals, snacks, dessertsEat animation, 6 seconds, hunger default
miscSpecial non-food items1 second, no animation

3. Add The Item ​

lua
local business = 'kff'

OGConsumable.RegisterCategory(business, 'burgers', 'food', {
    kff_burger = {
        label = 'KFF Burger',
        hunger = 65,
        stress = 3,
        progress = 'Eating Burger...',
        duration = 7,
        propPreset = 'burger',
        dirtyItem = 'gp_dirtyplate',
        ox = {
            description = 'A hot burger wrapped and ready to eat.',
            weight = 200,
            image = 'kff_burger.png',
            degrade = 1440,
            decay = true
        }
    }
})

4. Export Ox Items ​

Generate into the resource dist folder first:

powershell
.\tools\ps1\export-ox-items.ps1 -Apply

If the live ox target file only contains generated consumables, direct export is fine:

powershell
.\tools\ps1\export-ox-items.ps1 -OutputPath "F:\scripts\resources\[ox]\ox_inventory\data\items" -Apply

If the live ox file also contains ingredients, containers, dirty returns, or other non-consumables, merge the generated consumable entries instead of replacing the whole file.

5. Validate ​

powershell
.\tools\ps1\validate-consumables.ps1 -Strict
.\tools\ps1\test-consumables.ps1

Common Patterns ​

Simple Drink ​

lua
OGConsumable.RegisterDrink(business, 'kff_orange_soda', {
    label = 'Orange Soda',
    thirst = 60,
    stress = 2,
    progress = 'Drinking Soda...',
    propPreset = 'drink',
    dirtyItem = 'gp_dirtyglass',
    ox = {
        description = 'A cold fizzy orange drink.',
        weight = 130,
        image = 'kff_orange_soda.png'
    }
})

Simple Food ​

lua
OGConsumable.RegisterFood(business, 'kff_fries', {
    label = 'KFF Fries',
    hunger = 35,
    stress = 1,
    progress = 'Eating Fries...',
    propPreset = 'snack',
    dirtyItem = 'gp_dirtyplate',
    ox = {
        description = 'Crispy seasoned fries.',
        weight = 150,
        image = 'kff_fries.png'
    }
})

Locked Misc Item ​

lua
OGConsumable.RegisterCategory(business, 'dog_peds', 'misc', {
    pd_dog_treat = {
        label = 'Police Dog Treat',
        progress = 'Eating Dog Treat...',
        duration = 1,
        animation = false,
        prop = false,
        restrictions = {
            mode = 'any',
            whitelist = true,
            peds = { 'a_c_chop', 'a_c_husky', 'a_c_shepherd' },
            message = 'Only dog peds can use this treat.'
        },
        effects = {
            stamina = {
                restore = 100,
                duration = 600,
                interval = 500
            }
        },
        ox = {
            description = 'A stamina treat for police dog peds.',
            weight = 100,
            image = 'pd_dog_treat.png'
        }
    }
})
