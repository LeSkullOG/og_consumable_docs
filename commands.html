Commands ​

Use this page when you already know what command you need. For the normal item creation flow, start with Creating Items.

Tool Commands ​

Build easy .exe launchers for the helper scripts:

powershell
.\tools\build-tool-exes.ps1

The launchers live beside the PowerShell files and run the matching script:

text
build-resource.exe       -> build-resource.ps1
export-ox-items.exe      -> export-ox-items.ps1
format-businesses.exe    -> format-businesses.ps1
new-business.exe         -> new-business.ps1
publish-docs.exe         -> publish-docs.ps1
test-consumables.exe     -> test-consumables.ps1
validate-consumables.exe -> validate-consumables.ps1

You can use either style:

powershell
.\tools\format-businesses.exe -Apply
.\tools\validate-consumables.exe -Strict
.\tools\test-consumables.exe -Business blackstag
.\tools\build-resource.exe -Clean

Double-clicking an .exe with no options keeps the window open at the end so the output can be read. Commands that need options, like creating a new business, are still best run from PowerShell.

Create a new business file:

powershell
.\tools\new-business.ps1 -Business kff -Label "Korean Fried Finest" -Apply

Export all businesses:

powershell
.\tools\export-ox-items.ps1 -Apply

Export one business:

powershell
.\tools\export-ox-items.ps1 -Business blackstag -Apply

Compact all business consumable files:

powershell
.\tools\format-businesses.ps1 -Apply

Compact one business file:

powershell
.\tools\format-businesses.ps1 -Business beanmachine -Apply

Validate all businesses:

powershell
.\tools\validate-consumables.ps1

Validate one business:

powershell
.\tools\validate-consumables.ps1 -Business blackstag

Run strict warnings:

powershell
.\tools\validate-consumables.ps1 -Strict

Run the full local test runner:

powershell
.\tools\test-consumables.ps1

Build a clean runtime resource for the live server:

powershell
.\tools\build-resource.ps1 -Clean

Dev Server Commands ​

Dev commands are disabled by default for live. Temporarily set Config.TestCommands.enabled = true while testing.

text
/ogc_help
/ogc_check gp_stagcola
/ogc_dump gp_stagcola
/ogc_give gp_stagcola 1
/ogc_give gp_stagcola 1 {"batch":"test-001","maker":"Black Stag"}
/ogc_preview gp_stagcola
/ogc_use gp_stagcola
/ogc_returns gp_stagcola
/ogc_alcohol gp_stagreserve
/ogc_status
/ogc_list blackstag

Whitelist Admin Commands ​

Whitelist admin commands are enabled by default for live and use Config.WhitelistCommands.ace.

text
/ogc_whitelist add pd_dog_treat playerId
/ogc_whitelist add pd_dog_treat citizenid
/ogc_whitelist remove pd_dog_treat playerId
/ogc_whitelist remove pd_dog_treat citizenid
/ogc_whitelist list pd_dog_treat
/ogc_whitelist clear pd_dog_treat
